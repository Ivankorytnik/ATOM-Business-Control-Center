# Weekly Project Review MVP

Отдельный модуль для еженедельного ревью проектов **B2B / B2G / Каршеринг / Такси** по CMMT.

Регламент встречи: **каждый понедельник в 09:30**.

## Что умеет MVP

- постановка задач от встречи к встрече;
- вертикаль, проект/компания, ответственный, статус, приоритет;
- дата постановки и срок;
- прогресс и ожидаемый результат;
- фильтры и поиск;
- контроль просрочки и блокеров;
- история каждого изменения;
- снимок состояния на встрече;
- журнал прошлых ревью;
- диаграмма Ганта;
- экспорт/импорт JSON;
- хранение данных в localStorage браузера.

## Файлы

- `weekly-review.html` — интерфейс;
- `weekly-review.css` — стили;
- `weekly-review.js` — логика и хранение данных.

## Важно

Это MVP публичного тестового контура. Не использовать для конфиденциальных данных АО «КАМА» и персональных данных.

Следующий этап после проверки сценария: облачное хранение, роли пользователей, единая база и связь с CMMT / ЭЛМА / Альфа.
